# F1Z PRIME — отчёт о тестировании

Дата: 2026-10-11. Коммит: `dc8d086` (ветка `ccr-27c43927-xio4pi`). Прод на vps4: `9231a94`, миграция `0008`.

## Автотесты (локально, PostgreSQL `f1z_test`)
Команда: `python -m pytest -q` → **150 passed** (~95 с).

Покрытие по областям:
- **API/каталог/цены** (`test_api.py`): карточки товаров, цены по валютам, маски премиум-номеров, права.
- **Оплата и заказы** (`test_api.py`): идемпотентное создание заказа; оплата с баланса (нет денег → 402;
  повторная оплата → 409, без двойного списания); Stars через invoice + `process_stars_payment`
  идемпотентно при повторной доставке webhook; ручная оплата без двойной обработки (409); отмена возвращает
  остаток; лимит незакрытых заказов; клиент не может задать цену.
- **Склад номеров** (`test_phone_inventory.py`, 18 тестов): определение US/CA/UA/PL/BR (US≠CA по `+1`),
  нормализация, невалидные, неоднозначные (выбор, не угадывание), одиночное/массовое добавление, дедуп,
  остаток из реальных строк, автовыдача после оплаты, без оплаты — ничего, нет в наличии → 409, гонка за
  последним номером (ровно один победитель), отмена→возврат, список/поиск/фильтр, доступ обычного
  пользователя → 401. Плюс граничные случаи оплаты: недостаток баланса → ничего не выдано; двойная оплата
  с баланса → один номер; повтор webhook Stars + повторные прогоны worker → один номер.
- **Проверка владения** (`test_phone_verification.py`, 5 тестов): мок-коды фиктивны, заявка после оплаты +
  одобрение владельцем, запрет повторного решения (409), по умолчанию выключено, доступ пользователя → 401.
- **Автоматизация/worker** (`test_automation.py`): очередь задач, повтор с backoff, dead-letter,
  восстановление застрявших задач (имитация перезапуска worker), идемпотентность повторной выдачи, инциденты,
  возвраты.
- **RBAC/безопасность** (`test_rbac.py`, `test_security.py`, `test_masks.py`): права по ролям, маскирование
  секретов, защита эндпоинтов.
- **Промокоды/правила** (`test_promo_rules.py`): скидки, лимиты применений, dry-run правил.
- **Админка** (`test_admin_panel.py`, `test_miniapp_admin.py`): дашборд (включая `phones_available` и
  `failed_fulfillments`), пользователи, цены, страны, журнал.
- **Бот** (`test_bot.py`): команды и сценарии покупки.
- **Фронтенд-гард** (`test_frontend_static.py`): запрет опасных `useEffect` без блочного тела.

## Что проверено ТОЛЬКО в тестовой среде (не на боевых сервисах)
- Оплата Stars: через `process_stars_payment` с тестовым payload; реальные списания Stars в Telegram не
  выполнялись.
- Проверка владения номером: только мок-провайдер (фиктивные коды). Реального API оператора нет.
- Реальные деньги/возвраты в платёжных системах не инициировались.

## Известные ограничения
- Нет реального API подтверждения владения номером — выдача подтверждается владельцем вручную.
- E2E в браузере — смоук-уровень (рендер и отсутствие ошибок), не полный пользовательский путь с реальным
  Telegram WebView.
