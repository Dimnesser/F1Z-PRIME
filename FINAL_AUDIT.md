## Что реализовано в этой сессии (поверх готового движка)
- **Каталог и цены (STAGE 2):** методы каталога у провайдера (`get_catalog`: страны/сервисы/цены), TTL-кэш;
  Decimal-ценообразование с резолвингом наценки (сервис → страна → глобальная) и полом минимальной прибыли;
  «не настроено → не продаём» (`PricingNotConfigured`). Настройки `sms_*` (вкл/выкл, наценки, мин. прибыль,
  отключённые позиции, TTL). `provider_cost` сохраняется в активации для расчёта прибыли.
- **Backend API (STAGE 3):** `/api/sms/countries|services|prices|purchase|activations|activations/{id}|
  activations/{id}/cancel` — авторизация через initData (UserDep), серверное ценообразование, rate limit,
  идемпотентность (двойной тап → та же активная заявка), IDOR-guard, коды статусов через ServiceError.
  Админ: `/api/admin/sms/activations|summary|catalog|{id}/reconcile|{id}/cancel`.
- **Telegram Bot (STAGE 4):** кнопка «📱 Купить номер (SMS)» и `/sms`; поток страна→сервис→подтверждение→
  покупка; карточка активации (номер/статус/код/таймер) с «Обновить»/«Отменить»; при выключенном сервисе или
  сбое провайдера — понятное сообщение, без фиктивных данных.
- **Mini App (STAGE 5):** страница `/sms` (вкладки стран, сервисы с ценой и реальным остатком, покупка),
  живая карточка активации (polling 5с, авто-код с копированием, таймер, возврат, отмена), вход с главной.
- **Admin Panel (STAGE 6):** страница «SMS-активации» (сводка/прибыль, таблица со статус-фильтром, очередь
  `RECONCILIATION_REQUIRED` с действиями bind/refund, каталог с себестоимостью/ценой/прибылью). Наценки
  редактируются в Настройках (раздел SMS появляется автоматически).
- **Worker & Finance (STAGE 7):** `task_sms_restore` восстанавливает активации, зависшие после краша
  (списание прошло, номер не получен) — через безопасную сверку, без повторной покупки.

## Ограничения / что нужно для боевого запуска SMS
- Реальный `SMS_ACTIVATE_API_KEY` в `.env` на сервере (без ключа работает mock-провайдер — для разработки).
- Настроить наценки (Настройки → SMS) и включить `sms_enabled`; без наценки позиции не продаются (безопасно).
- Деплой новой версии на vps4 — по отдельному подтверждению владельца (миграция 0009 аддитивна).
