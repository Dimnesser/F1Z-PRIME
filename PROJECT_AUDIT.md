## Проверено и признано корректным (действий не требуется)
- **Авторизация Mini App (`security.py:31`)**: валидация `initData` по официальному алгоритму —
  HMAC-SHA256 с ключом `WebAppData`, сравнение через `hmac.compare_digest`, проверка `auth_date`
  (истечение и «дата в будущем»), лимит длины, строгий парсинг. Подделка подписи отвергается.
- **Токен админки (`admin_access.py`)**: короткоживущий (1 ч), переобмен `initData`; каждый админ-роут,
  кроме `/login` и `/telegram-login`, защищён зависимостью `P(...)` (проверено по всем `admin_*.py`).
- **IDOR (`public.py:390`)**: `order_detail` отдаёт 404, если `order.user_id != user.id`. Тикеты и платежи
  доступны только владельцу.
- **Идемпотентность оплаты (`payments.py`)**: повторная оплата с баланса → 409; повторный webhook Stars
  (`process_stars_payment`) идемпотентен; ручная оплата не обрабатывается дважды (409). Подтверждено тестами.
- **Атомарная выдача номера (`phones.py:reserve_for_order`)**: `SELECT FOR UPDATE SKIP LOCKED`, один номер не
  достаётся двум покупателям (тест гонки), выдача только после подтверждённой оплаты, возврат в пул при
  отмене/истечении. Остаток считается из реальных строк.
- **Возвраты (`refunds.py`)**: блокировка строки заказа + проверка существующего возврата → повторный возврат
  по заказу отклоняется (409); изменения баланса только через ledger (`refund_to_balance`); Stars-возврат
  помечается `refunded` лишь после подтверждения Telegram.
- **Промокоды (`promo.py`)**: скидка ограничена `max(0, min(d, subtotal − MIN_TOTAL_AFTER_DISCOUNT))` —
  отрицательная цена невозможна; `max_uses` и `max_uses_per_user` под `SELECT ... FOR UPDATE`; проверка
  `min_total`, срока действия; активация возвращается при отмене неоплаченного заказа.
- **Приватность**: телефонные номера и секреты не пишутся в логи (проверено grep). Покупателю номер виден
  только после выдачи; сотрудникам ключи показываются маской.
- **Rate limiting**: вход в админку (5 мин), лимит незакрытых заказов, лимиты на товар, лимит открытых
  тикетов, число попыток проверки, публичный эндпоинт отчёта об ошибках (размер + частота).
- **Бот**: long-polling (нет поверхности подделки вебхука); платежи Stars проходят `validate_precheckout`
  (payload + сумма + валюта + telegram_id).
- **Телеграм OTP/`.session`**: не извлекаются и не пересылаются; модуль проверки владения — только мок с
  фиктивными кодами.
